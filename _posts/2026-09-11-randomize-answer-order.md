---
title: "Randomize answer order"
date: 2026-09-11
kind: feature
tags: [Feature, Courses]
---

Shuffle the answer choices on a question so Trainees don't all see them in the same order.

- **Turn it on question by question** — a new Randomize order toggle on multiple choice and image choice screens in the Course builder, off by default, so nothing you've already published changes.
- **You still see the order you wrote** — choices stay as you entered them while you build and review; only Trainees see them shuffled.
- **The order holds while they answer** — each Trainee gets one order and keeps it through going back and retrying, so a question never rearranges itself mid-answer.
- **Everywhere training happens** — on the web and in the app, on Knowledge Check questions too, and alongside Select all that apply.
