A smoother sign-in, better document conversion, custom reports from your AI assistant, a roomier course builder, and fixes across forms, Opus Docs, the app and the dashboard.

### Improvements

- **A smoother sign-in.** Sign-in shows one method at a time, keeps what you typed when something goes wrong, accepts pasted and autofilled phone numbers, and lets you resend a code or go back from the code screen.
- **Better document conversion.** Converting a file to an Opus Doc keeps tables as real tables (allergen charts, for example) and handles large images and fill-in-the-blank lines better. Scanned PDFs that used to come out empty now convert too.
- **More reports from your AI assistant.** A connected assistant can now build, preview and save custom reports, and pull completions, content status and a person's training.
- **More room in the Course builder.** A zoom slider sets how large screens appear, full screen scrolls sideways, and you can add a screen by hovering the gap between two screens. When you remove a section, you can now keep the items in it.
- **Collapse the main menu on any page.** Admins can now collapse the left menu on every page, including pages without a second menu.
- **Easier matching questions in the app.** Long lists scroll on their own when you drag an answer toward the top or bottom of the screen.
- **HRIS adoption on the app's Team tab.** Locations that count people from your HRIS now show their adoption, as on the web, instead of asking you to set an employee count.

### Bug fixes

- Fixed an issue where forms could be submitted with required steps left unanswered, including when only a photo, video or note had been added.
- Fixed an issue in the app where people got stuck on matching, ordering, image-choice and title screens set to require watching a full video, because those screens don't show the video.
- Fixed several Opus Doc problems: pictures in docs could appear blank in the app, an Opus Doc linked on a Course screen showed the whole doc above the slide with no title, and library links in docs opened the browser instead of the item in the app.
- Fixed an issue where the "who's here" avatars in the doc editor showed everyone editing anything in your organization, not just people in the same document.
- Fixed an issue where tags with "Filterable in app" turned off still appeared as filters. Now only people who manage the library see them.
- Fixed an issue where the Course builder crashed when you opened a course with no lessons.
- Fixed an issue where managers saw menu links that led to a "not found" page.
- Fixed several dashboard problems: table search dropped letters as you typed, an item opened from a list took on the list's sort, columns and search, the side menu covered the page and blocked clicks while it slid open, and long user lists spilled past the dialog's buttons.
- Fixed an issue where Checklist PDF exports split cards across page breaks.
- Fixed small issues: on iOS, Create User wouldn't let you pick a language other than the default, Audit descriptions in the app showed raw formatting code, new folders could show a blank cover, "Premium Module" was shown without its space, and employee and location sync stopped updating for Square-connected organizations.
