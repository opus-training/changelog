Hand Ask Opus the Admin work, not just questions.

Ask Opus already answers questions about your training. This update lets it act like a signed-in Admin: pulling reports, answering questions from your organization's own data, and drafting content, all inside that Admin's own permissions.

*Example*: Ask for a location's completion rate instead of building a report, or have it start a draft while you review what matters.
