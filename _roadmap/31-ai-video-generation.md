Create training video from a prompt, the same way you already create images.

AI Video Generation works like the [AI image generator](https://help.opus.so/en/articles/12624782-how-to-edit-and-generate-images-with-ai-in-opus) already in Opus. Write a prompt describing what you want, generate a video, and use it directly in a Course.

Use it when filming isn't practical, or when a process is hard to capture on camera.
