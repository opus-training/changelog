Connect Opus to the assistants you already use, like Claude or ChatGPT.

Once connected, let the assistant do the work instead of doing it by hand. It builds content, takes actions, and pulls reports, all in plain language.

Ask it a tactical question, like what completion looks like at one location. Ask it a strategic one, like where you should focus this week. It answers both.

Opus sits alongside the other tools already connected to your assistant. Pull a completion report and drop it straight into a doc or a message, without switching between apps to do it.

It only sees what you can see in Opus, and it only does what you can already do.
